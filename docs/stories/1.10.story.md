# Story 1.10 — Suavizar Mensagens de Erro

**Status:** Ready
**Epic:** 1 — Qualidade e UX do Chatbot
**Story ID:** 1.10
**Prioridade:** Média
**Estimativa:** XS (1h de edição no n8n)

---

## Descrição

Quando o banco de dados não retorna resultados para entregas, valores ou contratos, o bot exibe mensagens com `❌` seguidas de texto negativo direto:

> "❌ Nao encontrei entregas para este projeto."

Esse padrão é frio e definitivo — não reconhece que a ausência de dados pode ser normal (projeto recém-iniciado, sem contratos ainda) e não sugere um próximo passo de forma acolhedora.

O mesmo problema ocorre no fallback do Q&A livre:
> "Nao consegui processar sua pergunta. Tente novamente ou use os menus disponiveis."

**Valor:** Mensagens de erro amigáveis mantêm o usuário engajado em vez de frustrá-lo. Em bots de governo, onde os dados podem estar incompletos por natureza, explicar o vazio é parte da boa experiência.

---

## Workflow de Desenvolvimento

```
1. Importar docs/flow/projeta-sc.json no n8n (Settings → Import)
2. Editar os nós: FormataEntregas, FormataValores, FormadaContratos, FormataRespostaLivre, FormataDetalheContrato
3. Substituir os blocos de erro em cada nó conforme textos aprovados nos ACs
4. Testar cada cenário de erro via webhook
5. Exportar (Download JSON) e substituir docs/flow/projeta-sc.json
6. Commitar
```

## Acceptance Criteria

### AC-1: FormataEntregas — erro suavizado
- [ ] Mensagem não contém `❌`
- [ ] Tom explica que não há entregas registradas (pode ser normal)
- [ ] Oferece alternativas de forma conversacional

**Texto aprovado:**
```
Ainda não há entregas registradas para esse projeto.

Quer ver os valores financeiros ou os contratos?
2️⃣ Ver Valores  3️⃣ Ver Contratos  4️⃣ Nova busca
```

### AC-2: FormataValores — erro suavizado
- [ ] Mensagem não contém `❌`
- [ ] Explica ausência sem tom negativo
- [ ] Oferece alternativas

**Texto aprovado:**
```
Ainda não há valores registrados para esse projeto.

Quer ver as entregas ou os contratos?
1️⃣ Ver Entregas  3️⃣ Ver Contratos  4️⃣ Nova busca
```

### AC-3: FormadaContratos — erro suavizado
- [ ] Mensagem não contém `❌`
- [ ] Explica ausência sem tom negativo
- [ ] Oferece alternativas

**Texto aprovado:**
```
Ainda não há contratos registrados para esse projeto.

Quer ver as entregas ou os valores?
1️⃣ Ver Entregas  2️⃣ Ver Valores  4️⃣ Nova busca
```

### AC-4: FormataRespostaLivre — fallback suavizado
- [ ] Mensagem não usa "Tente novamente" como instrução direta
- [ ] Tom compreensivo

**Texto aprovado:**
```
Não consegui responder a isso dessa vez. Pode tentar reformular a pergunta ou usar as opções abaixo:
```
*(o rodapé dinâmico existente permanece inalterado após esse texto)*

### AC-5: FormataDetalheContrato — erro suavizado
- [ ] Mensagem de erro existente (`⚠️ Erro ao carregar detalhes`) substituída por texto amigável

**Texto aprovado:**
```
Não consegui carregar os detalhes desse contrato. Tente selecioná-lo novamente ou volte à lista de contratos.
```

## Cenários de Teste

| Cenário | Ação | Resultado esperado |
|---------|------|--------------------|
| Projeto sem entregas | Selecionar projeto + opção 1 | Mensagem suavizada de AC-1 |
| Projeto sem valores | Selecionar projeto + opção 2 | Mensagem suavizada de AC-2 |
| Projeto sem contratos | Selecionar projeto + opção 3 | Mensagem suavizada de AC-3 |
| LLM Q&A falha | Simular falha no nó RespondePerguntas | Fallback do AC-4 |
| Detalhe de contrato falha | Selecionar contrato com dado corrompido | Mensagem amigável do AC-5 |
