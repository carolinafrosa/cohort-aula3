# Story 1.22 — Polir Labels e Emojis nos Formatadores de Dados

**Status:** Ready
**Epic:** 1 — Qualidade e UX do Chatbot
**Story ID:** 1.22
**Prioridade:** Baixa
**Estimativa:** XS (1h de edição no n8n)

---

## Descrição

Dois problemas de legibilidade nos nós de formatação, não cobertos pelas correções de acentos da Story 1.7:

**Problema A — Abreviação "Exec:" em contratos:**
`FormadaContratos` e `FormataDetalheContrato` exibem `📊 *Exec:* 67%`. A abreviação "Exec" não é intuitiva para o cidadão comum. Melhor: `*% Executado:*`.

**Problema B — Emoji repetido em Valores:**
`FormataValores` usa o mesmo emoji 💳 para os 4 indicadores financeiros:
```
💳 *Planejado:* R$ 1.200.000
💳 *Contratado:* R$ 980.000
💳 *Executado:* R$ 750.000
💳 *Pago:* R$ 680.000
```
Sem diferenciação visual, o usuário precisa ler cada label para distinguir — especialmente difícil no WhatsApp em fonte pequena. Emojis diferenciados criam hierarquia visual imediata.

**Valor:** Mensagens mais legíveis sem nenhuma alteração funcional — polimento de experiência com esforço mínimo.

## Acceptance Criteria

### AC-A: Substituir "Exec:" por "% Executado:" em contratos

- [ ] Em `FormadaContratos` (lista de contratos), a linha de execução de cada contrato exibe:
  ```
  📊 *% Executado:* 67%
  ```
- [ ] Em `FormataDetalheContrato`, a linha de execução exibe:
  ```
  📊 *% Executado:* 67%
  ```
- [ ] Nenhuma outra alteração no conteúdo desses nós

### AC-B: Diferenciar emojis em FormataValores

- [ ] Cada indicador financeiro usa um emoji distinto:

  | Campo | Emoji atual | Emoji novo |
  |-------|------------|-----------|
  | Planejado | 💳 | 💰 |
  | Contratado | 💳 | 📋 |
  | Executado | 💳 | ⚙️ |
  | Pago | 💳 | ✅ |

- [ ] O resultado esperado:
  ```
  💰 *Planejado:* R$ 1.200.000,00
  📋 *Contratado:* R$ 980.000,00
  ⚙️ *Executado:* R$ 750.000,00
  ✅ *Pago:* R$ 680.000,00
  ```

- [ ] O emoji de execução `📊 *Execução:*` (percentual) permanece como 📊
