# Story 1.40 — Corrige filtro Plano de Governo usando VIP em vez de BA

**Status:** Done
**Epic:** 1 — Qualidade e UX do Chatbot
**Story ID:** 1.40
**Prioridade:** Alta
**Estimativa:** XS (<1h)

---

## Descrição

Filtrar por "Plano de Governo: Sim" retornava 73 projetos; o sistema Projeta retorna 492.

**Causa raiz:** o filtro usava `BA.PLANO_GOVERNO = 'Sim'` (view `VW_PROJETO_BUSCA_AVANCADA_IA`), que é denormalizada com ~18,9M linhas (uma por projeto × município) e com valores em case diferente do esperado. A view `VW_IDENTIFICACAO_PROJETOS` tem a coluna `PLANO_GOVERNO` diretamente, com valores `'SIM'`/`'NÃO'` (maiúsculo), cobrindo 100% dos 8.886 projetos.

**Diagnóstico:**
```
TOTAL_VIP = 8.886 | TOTAL_BA = 18.939.706 | VIP_SEM_BA = 0
BA: NÃO=11.224.854 / SIM=7.714.852
VIP: NÃO=8.394 / SIM=492
```

---

## O que foi alterado

Nó `MontaBusca` — 3 substituições:

| Antes | Depois |
|-------|--------|
| `BA.PLANO_GOVERNO = 'Sim'` | `VIP.PLANO_GOVERNO = 'SIM'` |
| `BA.PLANO_GOVERNO = 'Não' OR IS NULL` | `VIP.PLANO_GOVERNO = 'NÃO'` |
| `BA.PLANO_GOVERNO` no SELECT | `VIP.PLANO_GOVERNO` no SELECT |
