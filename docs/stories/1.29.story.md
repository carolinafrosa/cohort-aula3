# Story 1.29 — Aviso de Processamento Durante Queries Longas

**Status:** Ready
**Epic:** 1 — Qualidade e UX do Chatbot
**Story ID:** 1.29
**Prioridade:** Média
**Estimativa:** XS (1–2h de edição no n8n)

---

## Descrição

Quando o Oracle 11g demora para responder (queries complexas, banco congestionado), o usuário fica sem resposta por vários segundos sem nenhuma indicação de que algo está acontecendo. Isso gera reenvio de mensagens e percepção de que o bot "travou".

Esta story adiciona um aviso proativo enviado logo após o início de uma consulta ao banco: *"Estou buscando as informações... isso pode levar alguns segundos."* O aviso é enviado antes da query Oracle ser concluída.

**Valor:** Quick win de UX. Reduz percepção de travamento e reenvios duplicados. Esforço mínimo, impacto imediato na percepção de qualidade.

---

## Workflow de Desenvolvimento

```
1. Importar docs/flow/projeta-sc.json no n8n
2. Identificar o nó imediatamente anterior a ConsultaProjetos (e variantes)
3. Inserir nó HTTP Request "AvisaBuscando" ANTES de cada nó de consulta Oracle:
   - Envia mensagem "Estou buscando... aguarde um momento 🔍" via Evolution API
   - Executa em paralelo com o início da query (não bloqueia)
4. Testar: confirmar que a mensagem aparece antes do resultado
5. Exportar e substituir docs/flow/projeta-sc.json
6. Commitar
```

---

## Acceptance Criteria

### AC-1: Mensagem de aviso enviada antes da consulta Oracle
- [ ] Um nó `AvisaBuscando` envia mensagem ao WhatsApp antes que `ConsultaProjetos` (e variantes `ConsultaProjetos1`, `ConsultaEntregas`, etc.) seja executada
- [ ] A mensagem tem tom amigável: *"Buscando as informações, aguarde um momento... 🔍"*

### AC-2: Aviso apenas em buscas (não em menus)
- [ ] O aviso é enviado apenas quando o fluxo vai consultar o Oracle (busca de projeto, valores, contratos, entregas)
- [ ] Navegação de menus e respostas estáticas NÃO disparam o aviso

### AC-3: Aviso não duplicado
- [ ] Se o resultado chega em menos de 1s (banco rápido), o aviso já foi enviado e o resultado complementa — não duplicar o aviso
- [ ] O usuário nunca recebe a mensagem "Buscando..." duas vezes para a mesma consulta (verificar no n8n execution log que o nó `AvisaBuscando` executa exatamente uma vez por consulta)

---

## Cenários de Teste

| Cenário | Ação | Resultado esperado |
|---------|------|--------------------|
| Busca normal | Pesquisar projeto qualquer | "Buscando..." aparece, depois resultado |
| Menu simples | Digitar "2" para ver valores de projeto já selecionado | Sem aviso "buscando" |
| Query lenta | Simular Oracle lento | Aviso aparece visivelmente antes do resultado |

---

## Escopo

**IN:**
- Nó `AvisaBuscando` inserido antes das queries Oracle de projetos, entregas, valores e contratos

**OUT:**
- Barra de progresso ou indicador visual avançado
- Cancelamento de busca em andamento
- Timeout configurável da query Oracle
