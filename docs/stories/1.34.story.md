# Story 1.34 — Aceitar Mensagens de Voz via Transcrição Whisper

**Status:** Ready
**Epic:** 1 — Qualidade e UX do Chatbot
**Story ID:** 1.34
**Prioridade:** Baixa
**Estimativa:** G (6–8h)

---

## Descrição

Cidadãos — especialmente idosos e pessoas com baixa alfabetização digital — preferem áudio ao texto no WhatsApp. O bot atual ignora mensagens de voz silenciosamente, sem nem informar que não processa áudio.

Esta story implementa transcrição automática de mensagens de voz usando a **API Whisper da OpenAI**. Quando o usuário envia um áudio, o fluxo:

1. Detecta que é uma mensagem de voz (não de texto)
2. Baixa o arquivo de áudio via Evolution API
3. Envia para o Whisper transcrever
4. Processa o texto transcrito normalmente pelo fluxo existente

**Valor:** Acessibilidade real para o público alvo do governo. Transcrição de áudio é o gateway para usuários que não digitam facilmente.

---

## Workflow de Desenvolvimento

```
1. Importar docs/flow/projeta-sc.json no n8n
2. Em FiltraMensagem, adicionar detecção de tipo de mensagem:
   - Se messageType == "audioMessage" → branch de transcrição
   - Se messageType == "conversation" → fluxo normal

3. Criar nó "BaixaAudio" (HTTP Request → Evolution API):
   - Baixar o arquivo de áudio da mensagem via /message/download/{instance}/{messageId}
   - Output: arquivo de áudio em base64 ou URL temporária

4. Criar nó "TranscreveAudio" (HTTP Request → OpenAI Whisper):
   - POST /v1/audio/transcriptions
   - Model: whisper-1
   - Language: pt (Português)
   - Output: texto transcrito

5. Criar nó "InjetaTranscricao":
   - Substituir o campo de mensagem de voz pelo texto transcrito
   - Adicionar prefixo "[Áudio transcrito]: " ao texto (para debug)

6. Reconectar ao fluxo normal a partir de ProcessaMensagem
7. Testar com áudios reais em WhatsApp
8. Exportar e substituir docs/flow/projeta-sc.json
9. Commitar
```

## Acceptance Criteria

### AC-1: Detecção de mensagens de voz
- [ ] `FiltraMensagem` ou nó equivalente detecta `messageType == "audioMessage"` (ou `pttMessage` para push-to-talk)
- [ ] Mensagens de voz não caem no fluxo padrão sem processamento

### AC-2: Download do áudio
- [ ] O nó `BaixaAudio` recupera o arquivo de áudio da mensagem via Evolution API
- [ ] Suporta os formatos de áudio do WhatsApp (OGG Opus, tipicamente)

### AC-3: Transcrição via Whisper
- [ ] O nó `TranscreveAudio` envia o áudio para a API Whisper com `language: "pt"`
- [ ] O texto transcrito é retornado em português com qualidade adequada para consultas de projeto

### AC-4: Integração com fluxo normal
- [ ] O texto transcrito é injetado no fluxo como se fosse uma mensagem de texto normal
- [ ] `ProcessaMensagem` processa o texto transcrito sem saber que veio de áudio

### AC-5: Feedback ao usuário
- [ ] Após transcrição, o bot confirma: *"Ouvi: '[transcrição]'. Buscando..."* — para que o usuário possa corrigir se a transcrição errou
- [ ] Se a transcrição falhar, o bot informa: *"Não consegui entender o áudio. Pode digitar sua consulta?"*

## Cenários de Teste

| Cenário | Ação | Resultado esperado |
|---------|------|--------------------|
| Áudio claro | Enviar áudio "buscar projeto em Florianópolis" | Transcrição correta → resultado de projeto |
| Áudio com ruído | Enviar áudio em ambiente barulhento | Transcrição melhor esforço → confirmação ao usuário |
| Áudio ininteligível | Enviar áudio de 1 segundo aleatório | Mensagem de fallback pedindo texto |
| Mensagem de texto | Enviar texto normal | Fluxo normal, sem passagem por transcrição |

## Escopo

**IN:**
- Detecção de `audioMessage` / `pttMessage`
- Download via Evolution API
- Transcrição via OpenAI Whisper
- Confirmação da transcrição ao usuário antes de processar

**OUT:**
- Suporte a mensagens de vídeo ou imagem
- Transcrição em outros idiomas (apenas português)
- Armazenamento de áudios transcritos

---

## Dependências

- `OPENAI_API_KEY` configurado no n8n (para Whisper)
- Evolution API deve expor endpoint de download de mídia para a instância `Projeta_SC`

---

## Riscos

- **Evolution API sem endpoint de download:** Algumas versões da Evolution API não expõem download de mídia de áudio — verificar antes de iniciar a implementação
- **Custo Whisper:** $0.006/minuto. Com uso moderado (100 áudios/dia de 30s médios), custo mensal < $9 — aceitável
- **Qualidade de transcrição de nomes próprios:** Whisper pode errar nomes de municípios como "Blumenau", "Jaraguá do Sul" — a normalização da Story 1.27 compensará parte dos erros
