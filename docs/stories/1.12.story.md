# Story 1.12 — Adicionar Frase Contextual de Abertura nos Resultados de Projeto

**Status:** Ready
**Epic:** 1 — Qualidade e UX do Chatbot
**Story ID:** 1.12
**Prioridade:** Média
**Estimativa:** S (2–3h de edição no n8n)

---

## Descrição

Quando o usuário seleciona um projeto da lista (ou quando há apenas um resultado), o bot exibe diretamente o bloco de dados sem nenhuma frase introdutória:

```
📄 *654/2025 - CONSTRUÇÃO DA PONTE*

🟡 *Situacao:* Em andamento
...
```

O ChatGPT nunca lança dados crus — ele contextualiza brevemente antes. Uma frase de abertura dinâmica ("Encontrei o projeto! Aqui estão os detalhes 📋") torna a resposta mais humana e prepara o usuário para os dados que vêm a seguir.

Adicionalmente, quando o percentual de execução é relevante (muito alto ou muito baixo), adicionar uma linha interpretativa transforma um dado frio num insight.

**Valor:** Pequena adição textual com grande impacto na percepção de conversa natural. Não altera nenhuma lógica do fluxo.

---

## Workflow de Desenvolvimento

```
1. Importar docs/flow/projeta-sc.json no n8n (Settings → Import)
2. Editar os nós FormataProjeto e ProcessaResultados (função descricaoProjeto)
3. Adicionar frase de abertura antes do bloco de dados
4. Adicionar linha interpretativa de execução (lógica condicional)
5. Testar selecionando projetos com diferentes percentuais
6. Exportar (Download JSON) e substituir docs/flow/projeta-sc.json
7. Commitar
```

---

## Acceptance Criteria

### AC-1: FormataProjeto — frase de abertura adicionada
- [ ] Mensagem começa com frase de abertura antes do bloco de dados
- [ ] Frase é concisa (1 linha)
- [ ] Bloco de dados existente permanece inalterado abaixo da frase

**Frase aprovada:** `Encontrei o projeto! Aqui estão os detalhes 📋\n\n`

**Resultado esperado:**
```
Encontrei o projeto! Aqui estão os detalhes 📋

📄 *654/2025 - CONSTRUÇÃO DA PONTE*

🟡 *Situação:* Em andamento
...
```

### AC-2: ProcessaResultados (função descricaoProjeto) — frase de abertura adicionada
- [ ] A função `descricaoProjeto` (usada quando há exatamente 1 resultado) também inclui a frase de abertura
- [ ] Consistência visual entre seleção de lista e resultado único

### AC-3: Linha interpretativa de execução (condicional)
- [ ] Quando `PERCENTUAL_EXEC >= 80`, adicionar após o percentual: ` — execução avançada ✅`
- [ ] Quando `PERCENTUAL_EXEC <= 10` e situação não for "Concluído", adicionar: ` — projeto em fase inicial`
- [ ] Para os demais valores, nenhuma linha adicional (não forçar interpretação em todos os casos)
- [ ] Quando `PERCENTUAL_EXEC` for null, undefined ou não numérico, nenhuma linha interpretativa é adicionada (usar `parseFloat()` e verificar `isNaN` antes de comparar)

**Exemplo com interpretação:**
```
📊 *Execução:* 85% — execução avançada ✅
```

## Cenários de Teste

| Cenário | Ação | Resultado esperado |
|---------|------|--------------------|
| Resultado único | Buscar "Ponte Hercílio Luz" | Frase de abertura antes dos dados |
| Seleção de lista | Buscar "escola", selecionar projeto 1 | Frase de abertura antes dos dados |
| Execução alta | Selecionar projeto com >80% execução | Linha "execução avançada ✅" |
| Execução baixa | Selecionar projeto com ≤10% execução | Linha "projeto em fase inicial" |
| Execução média | Selecionar projeto com 40-79% execução | Sem linha interpretativa extra |

- Mudança no menu de opções (1️⃣ Ver Entregas, etc.)
