# Story 1.39 — Sugestão "Você quis dizer X?" quando busca retorna 0 resultados

**Status:** Ready
**Epic:** 1 — Qualidade e UX do Chatbot
**Story ID:** 1.39
**Prioridade:** Média
**Estimativa:** M (3–5h)

---

## Descrição

Quando uma busca retorna 0 resultados, o cidadão fica sem orientação. Em vez de encerrar a conversa, o bot deve tentar detectar se o termo digitado é próximo de outro termo existente no banco e perguntar: *"Não encontrei projetos com 'ponte em Videira'. Você quis dizer ponto?"*

Casos de uso principais:
- Digitação errada: "ponte" → sugere "ponto crítico"
- Sinônimo não coberto: "calçadão" → sugere "calçamento"
- Abreviação desconhecida: "HRC" → sugere "Hospital Regional"

---

## Acceptance Criteria

### AC-1: Detecção de 0 resultados
- [ ] Quando `TOTAL_GERAL = 0` (ou array vazio), o fluxo entra no caminho de sugestão em vez do caminho de erro genérico

### AC-2: Geração da sugestão
- [ ] O bot envia mensagem no formato: *"Não encontrei projetos com '[termo]'. Você quis dizer '[sugestão]'?"*
- [ ] A sugestão é baseada em palavras existentes no campo `VIP.NOME` com distância de edição ≤ 2 (Levenshtein) ou similaridade fonética
- [ ] Se não há sugestão confiável (similaridade < limiar), exibe apenas: *"Não encontrei projetos com '[termo]'. Tente refinar sua busca."*

### AC-3: Confirmação
- [ ] Após a sugestão, o bot oferece opções: *1️⃣ Sim, buscar [sugestão]* / *2️⃣ Não, nova busca*
- [ ] Opção 1 executa a busca com o termo sugerido
- [ ] Opção 2 retorna ao menu inicial

### AC-4: Sem regressão
- [ ] Buscas com resultados continuam funcionando normalmente
- [ ] O caminho de erro atual (sem sugestão) permanece como fallback

---

## Escopo

**IN:**
- Nó de verificação de resultado zero
- Nó de geração de sugestão (Code node com Levenshtein ou chamada Groq)
- Nó de resposta com pergunta de confirmação
- Tratamento da resposta (sim/não) no `ProcessaMensagem`

**OUT:**
- Mudanças nos nós de busca existentes
- Sugestões para campos que não sejam `nome`

---

## Notas Técnicas

**Opção A (sem LLM):** Implementar Levenshtein em JavaScript no Code node. Contra a lista de palavras distintas do cache `filtrosDistintos.nomes` (se existir) ou contra os resultados top-10 de uma busca relaxada.

**Opção B (com LLM):** Após 0 resultados, chamar Groq com prompt: *"O usuário buscou '[termo]'. Sugira a correção mais provável para um nome de projeto de infraestrutura de SC."* Mais semântico, porém adiciona latência e custo.

Recomendação: Opção A para termos simples (1 palavra), Opção B como fallback para termos compostos.
