# Story 1.7 — Corrigir Acentuação em Mensagens Hardcoded

**Status:** Ready
**Epic:** 1 — Qualidade e UX do Chatbot
**Story ID:** 1.7
**Prioridade:** Alta
**Estimativa:** XS (1–2h de edição no n8n)

---

## Descrição

Todas as mensagens hardcoded no fluxo foram escritas sem acentuação correta: "Voce", "nao", "nao encontrei", "gostaria", "agora", entre outras. No WhatsApp, texto sem acento remete a sistemas legados ou spam — prejudica diretamente a percepção de qualidade do bot.

Esta story corrige a acentuação em todos os nós `Code` e `HTTP Request` que contêm mensagens estáticas para o usuário.

**Valor:** Primeiro passo obrigatório para humanizar o fluxo. Sem esta story, qualquer melhoria de tom e linguagem nas demais stories parte de uma base com erros ortográficos visíveis.

---

## Workflow de Desenvolvimento

```
1. Importar docs/flow/projeta-sc.json no n8n (Settings → Import)
2. Editar cada nó listado no Escopo — corrigir acentuação no campo de texto
3. Testar via webhook com mensagens que triggeram cada nó afetado
4. Exportar (Download JSON) e substituir docs/flow/projeta-sc.json
5. Commitar
```

## Acceptance Criteria

### AC-1: ProcessaMensagem — mensagem de timeout corrigida
- [ ] "Sua sessao expirou" → "Sua sessão expirou"
- [ ] "Ola!" → "Olá!"
- [ ] "voce" → "você" (todas as ocorrências)
- [ ] "Nao" → "Não" (todas as ocorrências)

### AC-2: RetornoReinicio — texto corrigido
- [ ] "voce gostaria" → "você gostaria"
- [ ] "Municipio" → "Município"
- [ ] "Numero do processo" → "Número do processo"
- [ ] "responsavel" → "responsável"

### AC-3: FormataEntregas — texto corrigido
- [ ] "Nao encontrei entregas" → "Não encontrei entregas"
- [ ] "Nova Busca" permanece como está (é label de menu)

### AC-4: FormataValores — texto corrigido
- [ ] "Nao encontrei valores" → "Não encontrei valores"

### AC-5: FormadaContratos — texto corrigido
- [ ] "Nao encontrei contratos" → "Não encontrei contratos"

- [ ] "Nao consegui processar" → "Não consegui processar"

- [ ] "Nao limite" → "Não limite"

## Cenários de Teste

| Cenário | Ação | Resultado esperado |
|---------|------|--------------------|
| Timeout | Aguardar 6 min sem interagir, enviar mensagem | Mensagem de expiração com acentos corretos |
| Reinício | Digitar "menu" | Mensagem de reinício com acentos corretos |
| Entregas vazia | Selecionar projeto sem entregas | "Não encontrei entregas" (com acento) |
| Erro Q&A | LLM falha no nó RespondePerguntas | Fallback com acentos corretos |
