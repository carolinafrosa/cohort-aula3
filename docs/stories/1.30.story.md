# Story 1.30 — Feedback Interativo Após Exibição de Resultado

**Status:** Ready
**Epic:** 1 — Qualidade e UX do Chatbot
**Story ID:** 1.30
**Prioridade:** Média
**Estimativa:** S (2–3h de edição no n8n)

---

## Descrição

Após exibir um resultado (projeto, valores, contratos), o bot simplesmente espera o próximo input sem orientar o usuário sobre o que pode fazer em seguida. Usuários frequentemente digitam texto livre tentando aprofundar a consulta, o que gera classificações incorretas.

Esta story adiciona um prompt de próximos passos ao final de cada resultado exibido, mantendo o usuário no fluxo guiado:

*"Posso te ajudar com mais alguma coisa sobre esse projeto? 1️⃣ Ver valores / 2️⃣ Ver contratos / 3️⃣ Nova busca"*

**Valor:** Reduz abandono pós-resultado e erros de navegação livre. Mantém o usuário orientado sem precisar memorizar os atalhos do menu.

---

## Workflow de Desenvolvimento

```
1. Importar docs/flow/projeta-sc.json no n8n
2. Identificar os nós de resposta que exibem resultado de projeto (RetornoProjeto)
3. Modificar a mensagem de RetornoProjeto para incluir prompt de próximos passos
   ao final: opções numeradas para valores, contratos e nova busca
4. Garantir que as opções estão alinhadas com o estado atual do contexto
   (usuario já tem projeto selecionado → opções são válidas)
5. Testar fluxo completo: busca → resultado → selecionar opção de próximo passo
6. Exportar e substituir docs/flow/projeta-sc.json
7. Commitar
```

## Acceptance Criteria

### AC-1: Prompt de próximos passos ao final do resultado de projeto
- [ ] Após `RetornoProjeto` exibir os dados do projeto, a mensagem inclui ao final: *"O que deseja ver sobre esse projeto? 1️⃣ Valores / 2️⃣ Contratos / 3️⃣ Nova busca"*
- [ ] As opções são numeradas e compatíveis com as opções que o `RoteadorPrincipal` já aceita

### AC-2: Opções funcionam corretamente
- [ ] Digitar "1" após ver resultado do projeto navega para valores do projeto
- [ ] Digitar "2" navega para contratos
- [ ] Digitar "3" reinicia para nova busca
- [ ] Nenhuma opção duplica estado no contexto

### AC-3: Não duplicar com menus já existentes
- [ ] O prompt de próximos passos não conflita com o menu principal que já existe em outros pontos do fluxo

### AC-4: Comportamento quando projeto não tem valores ou contratos
- [ ] Se o projeto selecionado não tem registros em `ConsultaValores`, a opção 1️⃣ (Valores) exibe mensagem amigável: *"Não há valores registrados para esse projeto ainda."*
- [ ] Se o projeto não tem contratos, a opção 2️⃣ (Contratos) exibe: *"Não há contratos registrados para esse projeto ainda."*
- [ ] Em ambos os casos, a opção 3️⃣ (Nova busca) sempre funciona normalmente

## Cenários de Teste

| Cenário | Ação | Resultado esperado |
|---------|------|--------------------|
| Resultado exibido | Ver qualquer projeto | Dados + prompt de próximos passos |
| Próximo passo 1 | Digitar "1" após resultado | Navega para valores |
| Próximo passo 2 | Digitar "2" após resultado | Navega para contratos |
| Próximo passo 3 | Digitar "3" após resultado | Nova busca iniciada |

## Escopo

**IN:**
- Prompt de próximos passos ao final do resultado em `RetornoProjeto`
- Validação que as opções numéricas funcionam no estado de "projeto selecionado"

**OUT:**
- Prompt de próximos passos para resultados de valores e contratos (avaliar em iteração futura)
- Personalização das sugestões por tipo de projeto

## Riscos
