# Story 1.25 — Fallback Inteligente em Buscas sem Resultado

**Status:** InProgress
**Epic:** 1 — Qualidade e UX do Chatbot
**Story ID:** 1.25
**Prioridade:** Alta
**Estimativa:** S (2–4h de edição no n8n)

---

## Descrição

Quando `ConsultaProjetos` retorna zero resultados, o fluxo exibe uma mensagem genérica e seca ("Nenhum resultado encontrado") sem orientar o usuário sobre o que fazer. Isso é um beco sem saída — o cidadão fica perdido.

Esta story substitui esse comportamento por um fallback inteligente em dois níveis:

1. **Empatia imediata:** mensagem humanizada reconhecendo que a busca não encontrou nada
2. **Sugestão automática via Groq:** chamar o LLM com os termos usados na busca e pedir 2–3 reformulações alternativas — ex: *"Não encontrei 'asfalto em Joinville'. Talvez você quis dizer 'pavimentação' ou 'recuperação de via'?"*

**Valor:** Zero resultados é o principal ponto de abandono do chatbot. Transformar esse momento em uma sugestão proativa retém o usuário e aumenta a assertividade percebida.

---

## Workflow de Desenvolvimento

```
1. Importar docs/flow/projeta-sc.json no n8n
2. Identificar o branch de "zero resultados" em RoteiaResultado
3. Criar nó "SugestaoFallback" (HTTP Request para Groq):
   - Input: termos usados na busca (de InterpretaConsulta/MontaBusca)
   - Prompt: pedir 2-3 termos alternativos em português
4. Criar nó "FormataFallback" (Code): formatar sugestões como mensagem empática
5. Conectar ao nó de resposta WhatsApp existente
6. Testar com termos que retornam zero resultados
7. Exportar e substituir docs/flow/projeta-sc.json
8. Commitar
```

## Acceptance Criteria

### AC-1: Detecção de zero resultados
- [x] Quando `ConsultaProjetos` retorna array vazio, o fluxo desvia para o branch de fallback (via RoteiaResultado output[2] → SugestaoFallback)
- [x] O branch de fallback não conflita com o fluxo normal de resultados

### AC-2: Mensagem empática
- [x] A resposta inicial ao zero resultado é humanizada: *"Não encontrei nada com '[termos]'. Vamos tentar de outro jeito?"*
- [x] A mensagem inclui os termos que o usuário usou (para mostrar que foi entendido)

### AC-3: Sugestões automáticas via Groq
- [x] O nó `SugestaoFallback` chama o Groq com os termos da busca e retorna 2–3 alternativas (llama-3.1-8b-instant)
- [x] As sugestões são exibidas como opções numeradas: *"1️⃣ pavimentação / 2️⃣ recuperação de rodovia / 3️⃣ buscar por município"*
- [x] Se o Groq falhar, o fallback exibe apenas a mensagem empática sem sugestões (graceful degradation)

### AC-4: Retorno ao fluxo normal
- [ ] Ao selecionar uma sugestão numerada, o fluxo retorna ao início da busca (validar no n8n — ProcessaMensagem já suporta nova busca via contexto)
- [x] A opção de "nova busca livre" (0️⃣) está sempre disponível

## Cenários de Teste

| Cenário | Ação | Resultado esperado |
|---------|------|--------------------|
| Termo inexistente | Buscar "asfalto Joinville" | Mensagem empática + 2-3 sugestões |
| Município sem projetos | Buscar projeto em cidade sem dados | Mensagem empática + sugestão de categoria |
| Groq indisponível | Simular timeout do Groq | Apenas mensagem empática, sem sugestões — sem erro |
| Selecionar sugestão | Digitar "1" após receber sugestões | Busca reiniciada com termo sugerido |

---

## Escopo

**IN:**
- Branch de fallback no `RoteiaResultado` para zero resultados
- Chamada ao Groq para sugestões de reformulação
- Formatação das sugestões como opções numeradas

**OUT:**
- Alteração da lógica de busca ou do `MontaBusca`
- Sugestões para outros tipos de zero resultado (entregas, contratos — avaliar em story futura)
- Persistência de histórico de buscas sem resultado

---

## Dependências

- Story 1.27 (normalização geográfica) — recomendado implementar antes para reduzir casos de zero resultado por apelido de município

---

## Riscos

- **Groq sugere termos incorretos:** O Groq pode sugerir reformulações que também não existem no banco → as sugestões são orientativas, não garantidas; o usuário sempre pode fazer nova busca livre
- **Loop de zero resultados:** Usuário seleciona sugestão que também retorna zero → limitar a 1 nível de recursão de fallback
