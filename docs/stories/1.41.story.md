# Story 1.41 — Typing indicator imediato ao receber mensagem

**Status:** Ready
**Epic:** 1 — Qualidade e UX do Chatbot
**Story ID:** 1.41
**Prioridade:** Alta
**Estimativa:** S (1–2h)

---

## Descrição

O bot demora alguns segundos para responder (processamento + LLM). Durante esse tempo o usuário não vê nenhum feedback visual, parecendo que a mensagem foi ignorada.

A solução é disparar o `sendPresence` (indicador de digitação do WhatsApp) logo após receber e filtrar a mensagem — antes de qualquer chamada LLM ou consulta Oracle.

---

## Como implementar no n8n UI

### Passo 1 — Criar o nó `EnviaDigitando`

Adicionar um **Code node** chamado `EnviaDigitando` com o seguinte código:

```javascript
const BASE     = 'https://n8n-evolution-api.lkpafu.easypanel.host';
const INSTANCE = 'Projeta_SC';

// Extrai o número de quem enviou a mensagem
const body = $input.item.json?.body || $input.item.json;
const numero =
  body?.data?.key?.remoteJid ||
  body?.data?.message?.key?.remoteJid ||
  body?.remoteJid || '';

if (numero) {
  try {
    const creds = await $credentials.get('httpHeaderAuth');
    await $http.request({
      method: 'POST',
      url: `${BASE}/chat/sendPresence/${INSTANCE}`,
      headers: { 'Content-Type': 'application/json', 'apikey': creds.value },
      body: { number: numero, options: { presence: 'composing', delay: 1500 } }
    });
  } catch (_) {
    // ignora falha — não pode travar o fluxo principal
  }
}

return $input.item;
```

### Passo 2 — Posicionar o nó

Inserir `EnviaDigitando` **entre `FiltraMensagem` e `ProcessaMensagem`**:

```
Whatsapp → FiltraMensagem → EnviaDigitando → ProcessaMensagem → ...
```

### Passo 3 — Exportar e substituir

Exportar o fluxo e substituir `docs/flow/projeta-sc.json`.

## Acceptance Criteria

- [ ] Ao enviar qualquer mensagem, o indicador "digitando..." aparece no WhatsApp em até 1 segundo
- [ ] Se o `sendPresence` falhar (rede/API), o fluxo continua normalmente sem erro
- [ ] Não há duplicação com os `sendPresence` existentes nos nós de resposta
